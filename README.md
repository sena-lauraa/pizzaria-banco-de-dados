Banco de Dados - Pizzaria
Projeto de banco de dados relacional desenvolvido em MySQL, com o objetivo de simular o gerenciamento de uma pizzaria.
O projeto foi desenvolvido para praticar conceitos de banco de dados, modelagem relacional e consultas SQL.

Sobre o projeto
O banco de dados permite organizar informações relacionadas aos clientes, endereços, produtos, categorias e pedidos realizados na pizzaria.
A estrutura foi criada pensando em um cenário de pedidos, desde o cadastro do cliente até o registro dos produtos incluídos em cada pedido.

Estrutura do banco
O banco de dados possui as seguintes tabelas:

- cliente – armazena os dados dos clientes.
- endereco – armazena os endereços relacionados aos clientes.
- categoria – organiza os produtos por categorias.
- produto – armazena os produtos disponíveis para venda.
- pedido – registra os pedidos realizados pelos clientes.
- item_pedido – registra os produtos e suas respectivas quantidades em cada pedido.

Tecnologias utilizadas
- MySQL
- SQL
- MySQL Workbench

Arquivos

`pizzaria.sql`
Arquivo responsável pela criação do banco de dados, tabelas e inserção dos dados utilizados no projeto.

`consultas.sql`
Arquivo contendo consultas SQL realizadas sobre o banco de dados, incluindo consultas com filtros, relacionamentos, agrupamentos e funções de agregação.

Como executar o projeto
1. Instale o MySQL e o MySQL Workbench.
2. Abra o arquivo `pizzaria.sql` no MySQL Workbench.
3. Execute o script para criar o banco de dados e suas tabelas.
4. Após a criação do banco, abra o arquivo `consultas.sql`.
5. Execute as consultas para visualizar e analisar os dados.
